# Phase 1: AI-Native Development

**Duration**: 35-45 hours | **Modules**: 9

Master the art of AI-assisted development. Learn to use AI coding tools effectively, engineer prompts for maximum impact, and debug with AI assistance.

## What You'll Learn

- AI coding assistants (GitHub Copilot, Cursor, Claude)
- Running local models (Ollama, LM Studio)
- Advanced prompt engineering techniques
- AI-powered code generation and debugging
- CLI-based AI agents

## Key Skills

After completing this phase, you'll be able to:

- Choose the right AI tool for each task
- Write effective prompts for code generation
- Debug complex issues with AI assistance
- Run models locally for privacy and speed
- Use CLI tools for automation
