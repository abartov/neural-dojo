# Phase 6: Deep Learning

**Duration**: 35-45 hours | **Modules**: 7

Build neural networks from scratch. Understand the fundamentals that power modern AI, from basic perceptrons to transformers.

## What You'll Learn

- Neural network architecture and math
- PyTorch fundamentals and best practices
- Training deep networks effectively
- Convolutional networks for images
- Recurrent networks for sequences
- Backpropagation mechanics
- Transformer architecture

## Heureka Moments :crystal_ball:

**Module 6.6 - Backpropagation**: Understand how neural networks actually learn through gradient descent. The chain rule enables credit assignment through millions of parameters.

**Module 6.7 - Transformers**: The architecture behind GPT, Claude, and modern AI. Attention mechanisms let models focus on relevant information.

## Key Skills

After completing this phase, you'll be able to:

- Implement neural networks from scratch
- Train and debug PyTorch models
- Design CNNs for computer vision
- Build RNNs for sequence modeling
- Understand transformer architectures
- Apply transfer learning
