# Curriculum Overview

Neural Dojo is a comprehensive 60-module curriculum designed to transform you from AI novice to AI-fluent practitioner.

## At a Glance

| Metric | Value |
|--------|-------|
| **Total Modules** | 60 |
| **Phases** | 13 |
| **Estimated Hours** | 230-310 |
| **Duration** | 52-62 weeks |

## Phases

## Learning Philosophy

1. **Theory Before Practice** - Understand WHY before HOW
2. **Progressive Disclosure** - Start simple, add complexity
3. **Active Learning** - Hands-on exercises and real projects
4. **Production Focus** - Build deployable, real-world systems

## Heureka Moments :crystal_ball:

Throughout the curriculum, look for :crystal_ball: **Heureka Moments** - transformative insights that fundamentally change how you think about AI:

- **Embeddings as Semantic Space** - Math works on meaning!
- **Attention Mechanism** - How transformers "see" relationships
- **Backpropagation** - How neural networks learn
- And many more...
