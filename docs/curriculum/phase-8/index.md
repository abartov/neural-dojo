# Phase 8: Classical ML

**Duration**: 12-15 hours | **Modules**: 3

Master traditional machine learning. Not everything needs deep learning - classical methods are faster, more interpretable, and often more effective.

## What You'll Learn

- Scikit-learn for rapid prototyping
- Gradient boosting (XGBoost, LightGBM)
- Time series forecasting

## Modules

| # | Module | Hours | Description |
|---|--------|-------|-------------|
| 8.1 | [Scikit-learn](../notes/module_36_constitutional_ai.md) | 4-5 | Classical ML toolkit |
| 8.2 | [Gradient Boosting](../notes/module_37_tabular_ml.md) | 4-5 | XGBoost and friends |
| 8.3 | [Time Series](../notes/module_38_time_series.md) | 4-5 | Forecasting and analysis |

## Key Skills

After completing this phase, you'll be able to:

- Build ML pipelines with scikit-learn
- Apply gradient boosting for tabular data
- Forecast time series data
- Choose between classical and deep learning
