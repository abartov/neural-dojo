# Phase 3: Vector Search & RAG

**Duration**: 16-20 hours | **Modules**: 4

Build production-ready Retrieval-Augmented Generation systems. Learn to give LLMs access to your data without fine-tuning.

## What You'll Learn

- Vector database concepts and options
- Building RAG pipelines from scratch
- Advanced retrieval techniques
- Evaluating RAG system quality

## Modules

| # | Module | Hours | Description |
|---|--------|-------|-------------|
| 3.1 | [Vector Databases](../notes/module_11_vector_databases.md) | 4-5 | Store and search embeddings |
| 3.2 | [RAG Systems](../notes/module_12_rag_systems.md) | 4-5 | Create your first RAG system |
| 3.3 | [RAG vs Fine-tuning](../notes/module_13_rag_vs_finetuning.md) | 4-5 | When to use which approach |
| 3.4 | [Advanced RAG](../notes/module_14_advanced_rag_patterns.md) | 4-5 | Hybrid search, reranking, and more |

## Key Skills

After completing this phase, you'll be able to:

- Choose and configure vector databases
- Build end-to-end RAG pipelines
- Implement advanced retrieval strategies
- Evaluate and improve RAG quality
- Handle production RAG challenges
