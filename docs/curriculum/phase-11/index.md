# Phase 11: AI for Infrastructure

**Duration**: 8-10 hours | **Modules**: 2

Apply AI to cloud operations and infrastructure management. Use AI to monitor, predict, and automate infrastructure.

## What You'll Learn

- Cloud AI services (AWS, GCP, Azure)
- AIOps for intelligent operations
- Predictive monitoring
- Automated remediation

## Modules

| # | Module | Hours | Description |
|---|--------|-------|-------------|
| 11.1 | [Cloud AI](../notes/module_53_ai_cloud_management.md) | 4-5 | AWS, GCP, Azure AI services |
| 11.2 | [AIOps](../notes/module_54_aiops_log_analysis.md) | 4-5 | AI for operations |

## Key Skills

After completing this phase, you'll be able to:

- Use cloud AI services effectively
- Implement predictive monitoring
- Build automated remediation
- Apply AI to infrastructure problems
