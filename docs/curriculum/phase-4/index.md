# Phase 4: Frameworks & Agents

**Duration**: 28-35 hours | **Modules**: 7

Master the major AI frameworks and build autonomous agents. Learn LangChain, LangGraph, LlamaIndex, and multi-agent systems.

## What You'll Learn

- LangChain fundamentals and advanced patterns
- LangGraph for complex workflows
- LlamaIndex for data frameworks
- Building AI agents with tools
- Agent memory systems
- Multi-agent orchestration

## Modules

| 4.7 | [Agents in Production](../notes/module_21_ai_agents_in_production.md) | 4-5 | Deploying agent systems |

## Key Skills

After completing this phase, you'll be able to:

- Build complex LangChain applications
- Design stateful workflows with LangGraph
- Use LlamaIndex for data-heavy applications
- Create autonomous agents with tools
- Implement memory systems
- Orchestrate multi-agent systems
