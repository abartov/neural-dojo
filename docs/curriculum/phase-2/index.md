# Phase 2: Generative AI

**Duration**: 20-25 hours | **Modules**: 5

Understand how Large Language Models work under the hood. This phase builds the theoretical foundation for everything that follows.

## What You'll Learn

- How LLMs process and generate text
- Tokenization and its impact on performance
- Text generation strategies (temperature, top-p, etc.)
- Embeddings and semantic representation
- Vector spaces and similarity

## Modules

| # | Module | Hours | Description |
|---|--------|-------|-------------|
| 2.1 | [Intro to LLMs](../notes/module_06_intro_to_llms.md) | 4-5 | How language models work |
| 2.2 | [Tokenization](../notes/module_07_tokenization.md) | 3-4 | Breaking text into tokens |
| 2.3 | [Text Generation](../notes/module_08_text_generation.md) | 4-5 | Sampling strategies and parameters |
| 2.4 | [Embeddings](../notes/module_09_embeddings.md) | 4-5 | Representing meaning as vectors |
| 2.5 | [Vector Spaces](../notes/module_10_vector_spaces.md) | 4-5 | :crystal_ball: Math works on meaning! |

## Heureka Moment :crystal_ball:

**Module 2.5 - Vector Space**: Discover how mathematical operations work on semantic meaning. The famous example: `king - man + woman ≈ queen`. This insight unlocks how we can compute with language.

## Key Skills

After completing this phase, you'll be able to:

- Explain how LLMs generate text
- Optimize prompts based on tokenization
- Tune generation parameters for different tasks
- Create and use embeddings
- Build semantic similarity systems
