# Phase 7: Advanced GenAI

**Duration**: 20-25 hours | **Modules**: 5

Go beyond using models to customizing them. Learn fine-tuning, efficient adaptation techniques, and how models are aligned.

## What You'll Learn

- Full fine-tuning techniques
- LoRA and parameter-efficient methods
- Diffusion models for image generation
- RLHF and alignment
- Code generation model internals

## Modules

| # | Module | Hours | Description |
|---|--------|-------|-------------|
| 7.1 | [Fine-tuning LLMs](../notes/module_32_finetuning_llms.md) | 4-5 | Customize models for your task |
| 7.2 | [Diffusion Models](../notes/module_33_diffusion_models.md) | 4-5 | Image generation from noise |
| 7.3 | [Code Gen Models](../notes/module_34_code_generation_models.md) | 4-5 | How Copilot works |
| 7.4 | [RLHF](../notes/module_35_rlhf.md) | 4-5 | :crystal_ball: Aligning AI with humans |

## Heureka Moment :crystal_ball:

**Module 7.4 - RLHF**: Understand how models like Claude are trained to be helpful, harmless, and honest. Reinforcement Learning from Human Feedback bridges the gap between capability and alignment.

## Key Skills

After completing this phase, you'll be able to:

- Fine-tune models on custom data
- Apply LoRA for efficient adaptation
- Understand diffusion model mechanics
- Explain alignment techniques
- Work with code generation models
