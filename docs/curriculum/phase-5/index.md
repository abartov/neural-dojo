# Phase 5: Multimodal AI

**Duration**: 12-15 hours | **Modules**: 3

Expand beyond text to work with voice, images, and video. Build systems that understand and generate multiple modalities.

## What You'll Learn

- Speech-to-text and text-to-speech
- Image understanding and generation
- Video analysis and processing
- Multimodal model architectures

## Modules

| # | Module | Hours | Description |
|---|--------|-------|-------------|
| 5.1 | [Speech AI](../notes/module_22_speech_ai.md) | 4-5 | Speech recognition and synthesis |
| 5.2 | [Vision AI](../notes/module_23_vision_ai.md) | 4-5 | Image understanding and generation |
| 5.3 | [Video AI](../notes/module_24_video_ai.md) | 4-5 | Video analysis and processing |

## Key Skills

After completing this phase, you'll be able to:

- Build voice-enabled applications
- Process and analyze images with AI
- Work with video content
- Combine modalities in applications
