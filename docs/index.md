## Learning Path

```
Phase 0: Prerequisites          → Set up your environment
Phase 1: AI-Native Development  → Use AI as your coding partner
Phase 2: Generative AI          → Understand how LLMs work
Phase 3: Vector Search & RAG    → Build intelligent search
Phase 4: Frameworks & Agents    → Master LangChain & agents
Phase 5: Multimodal AI          → Work with images, audio, video
Phase 6: Deep Learning          → Build neural networks
Phase 7: Advanced GenAI         → Fine-tuning & RLHF
Phase 8: Classical ML           → Scikit-learn & XGBoost
Phase 9: AI Safety              → Evaluation & red teaming
Phase 10: MLOps                 → Deploy & monitor ML systems
Phase 11: AI for Infrastructure → Cloud AI & AIOps
Phase 12: History               → How we got here
```
