# Module 3 Examples: AI-Powered Code Generation

This directory contains hands-on examples demonstrating AI-powered code generation techniques.

## Prerequisites

```bash
pip install -r requirements.txt
```

## Examples

### Example 1: Basic Code Generation
**File**: `01_basic_generation.py`
**Description**: Demonstrates generating simple functions with specifications
**Run**: `python 01_basic_generation.py`

### Example 2: Test Generation
**File**: `02_test_generation.py`
**Description**: Generate comprehensive test suites for existing code
**Run**: `python 02_test_generation.py`

### Example 3: Refactoring Code
**File**: `03_refactoring.py`
**Description**: Use AI to refactor and improve existing code
**Run**: `python 03_refactoring.py`

### Example 4: API Client Generation
**File**: `04_api_client_generation.py`
**Description**: Generate complete API client with error handling
**Run**: `python 04_api_client_generation.py`

### Example 5: CLI Tool Generation
**File**: `05_cli_generation.py`
**Description**: Generate command-line interfaces with argparse
**Run**: `python 05_cli_generation.py`

### Project: Complete Package Generation
**Directory**: `project/`
**Description**: Full Python package generated with AI assistance
**See**: `project/README.md`

## Note

These examples use Claude API for code generation. Each example:
1. Shows the prompt used
2. Generates the code
3. Demonstrates testing the generated code
4. Provides lessons learned

All generated code should be reviewed before production use!
